## 修复明细

### 1. 请求失败后一直等待

原问题：HTTP 200 但响应为空时，直接读取 `data.code` 会在回调中抛错，Promise 不结束，页面可能一直显示加载状态。

修复：校验响应结构，格式异常时明确提示并拒绝请求；所有 API 请求设置 15 秒超时，微信登录凭证获取设置 10 秒超时。保留域名、连接拒绝和网络超时的不同提示，不自动重试写入请求。

### 2. 登录重复提交和过期响应

原问题：连续点击可同时登录；离开页面或更换账号后，旧请求可能覆盖当前登录态。普通接口失败还会被误提示为“没有微信授权环境”。

修复：微信、账号、注册和演示登录共用提交锁；成功、失败均收尾加载状态；校验登录返回结构；离开页面、服务器或会话变化后忽略旧结果。移除误导性的自动演示登录引导，将按钮文案改为实际行为“微信快捷登录”。

### 3. 预约时间和老人档案加载

原问题：任何时间进入预约页都默认当天 09:00，下午下单时已是过去；无联系电话的老人会产生 `undefined` 表单值；档案请求缺少错误收尾和账号隔离。

修复：默认取至少 35 分钟后的五分钟整点，限制在当前时间选择器的 08:00—18:00 范围，晚间转至次日；提交前再次校验至少提前 30 分钟。统一空联系人字段，合并重复档案读取、拦截旧会话结果、显示失败重试，并处理已选老人从列表移除的情况。

### 4. 地址与坐标不一致

原问题：选点后手改地址仍携带旧坐标；后端在用户换地址后仍会沿用老人旧坐标，无坐标时甚至使用默认北京坐标；追踪接口也会再次补回旧坐标。

修复：预约页和档案页手改地址即清除坐标；后端仅在地址相同且老人坐标有效时继承位置，地址变化且无选点时保持未知；拒绝半组或越界坐标；追踪接口遵循相同地址规则，不混合不同来源的经纬度。保留未知位置时的文字地址，导航提示“暂无目的地坐标”。

已有订单里原先已经写入的默认坐标未批量更改：这些值无法仅凭坐标可靠区分真假，需要对对应地址重新选点核实。

### 5. 订单追踪停止、旧数据覆盖和状态不更新

原问题：返回详情页命中缓存后不重启追踪；旧账号请求能覆盖新地图；坐标消失时旧标记还在；用真假值判断坐标会误判有效的 0；追踪状态变化后订单操作按钮仍可能停留在旧状态。

修复：返回缓存页恢复轮询，隐藏和销毁页面时停止；追踪请求合并、校验账号和订单；清空无效位置及旧路线，位置有效时才展示地图；状态变化触发详情刷新。取消和确认失败也会正确释放操作锁，不再产生未处理的拒绝。

### 6. 工作台导航和定位回调

原问题：任务卡片压缩数据时丢掉经纬度，导航因而回落到默认北京；模板字符串 ID 与数字 ID 不匹配；离开工作台后的定位回调仍可能上传。

修复：保留任务坐标，兼容字符串 ID；导航只使用有效目的地坐标；完成工作台档案读取后才启动位置上报；合并尚未完成的定位调用，并在回调里重新检查页面和会话，负速度归零。工作台资料尚未就绪时不能切换工作状态。另补充按需分页、触底和按钮加载，避免较早安排永远被最近 20 条订单遮住；增加第 21 条订单才出现待上门任务的回归用例。

### 7. 家属绑定选错老人和重复申请

原问题：查询后修改手机号，页面仍保留上一次命中的老人；旧查询结果可能覆盖新手机号；申请可连续提交，失败缺少收尾。

修复：手机号变化立即清空已选老人，使用查询版本和会话校验丢弃旧结果；绑定和撤销增加重复提交保护与失败收尾；列表加载合并请求、提供失败重试，加载失败时不再显示误导性的空列表提示。

### 8. 弹层重开消失与拖动迟滞

原问题：关闭弹层后迅速重开，旧关闭定时器仍会把新弹层隐藏；拖动时 CSS 过渡持续生效，手指与面板不同步。

修复：重开及组件销毁时清理关闭定时器；拖动期间关闭过渡，松手后保留原有 280ms 回弹；处理手势取消；移除冲突的重复移动事件绑定。

### 9. 更换服务器后仍显示旧服务

原问题：服务详情里用于清除旧服务的判断条件写反，新服务器读取失败时仍展示旧服务器的数据。

修复：服务器变化立即清空旧服务，重新读取并显示可重试错误状态。

### 10. 直接进入页面后无法返回

原问题：单页启动或直接进入档案、评价页面时，保存后只调用返回上一页，没有页面栈就留在原地。

修复：有历史栈正常返回；无历史栈或返回失败时，档案页回个人中心，评价页回订单详情。评价缺少订单 ID 时禁止提交。

## 重跑方式

项目根目录 PowerShell：

```powershell
node --test (Get-ChildItem miniprogram/tests/*.test.cjs).FullName
node miniprogram/scripts/smoke-api.cjs
```

接口冒烟需要本地后端运行、开发模式允许演示登录，默认访问 `http://127.0.0.1:8080/api`。可用 `MINIPROGRAM_API_BASE` 环境变量指定其他测试地址。脚本不会输出 Token。

后端目录运行：

```powershell
mvn -Dmaven.compiler.proc=full '-Dtest=OrderAddressSnapshotTest,LocationTrackingTest,DispatchScoreEngineTest,JacksonConfigTest,LanAddressPickerTest' test
```

当前机器使用 JDK 23；显式启用注解处理后 Lombok 才正常生成方法，因此上述命令包含 `maven.compiler.proc=full`。没有执行会直接写当前数据库、且未隔离事务的既有整条订单流集成测试。

## 验证边界与后续验收

- 微信扫码授权、手机系统权限弹窗、实际 GPS 和导航需要真机验收；本次模拟器及逻辑测试不能证明这些平台能力全部可用。
- 没有采集手机性能轨迹，因此不宣称已消除所有真机掉帧。保留分类滑动、按钮反馈、预约成功反馈和弹层回弹，修复了可复现的请求及生命周期阻塞。
- 工作台超过 20 条的数据访问通过隔离分页测试验证；本次现有演示账号最多 6 条订单，未向真实数据库批量造单。
- `SharedArrayBuffer`、基础库灰度和系统信息 API 提示属于开发环境警告，未当作业务编译错误处理。
- 真机再次调试时，重新编译后扫码加载当前代码。局域网连接仍要求手机能访问电脑当前地址；超时提示可以帮助定位问题，但不能修复 WiFi 隔离或操作系统网络限制。
