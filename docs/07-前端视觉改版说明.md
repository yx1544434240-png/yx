# 前端视觉改版说明

本次把管理后台与微信小程序统一为「颐邻」社区服务界面，采用暖白底色、深绿色主色和少量暖棕色价格强调。保留现有后端接口与业务流程。

## 界面调整

- 管理后台：重做登录页、侧边导航、顶部账号区、工作台和智能派单页；统一订单、老人档案、人员、项目和反馈页面的标题、表格、状态标签及弹窗。
- 工作台：展示真实累计订单、待安排服务、履约中订单和已完成服务，增加待办队列、社区概况、趋势图与人员情况；数据加载失败时显示可恢复的状态。
- 智能派单：预约队列与人员建议分栏展示，窄屏纵向排列；候选人按最新调度轮次和每人的最新评分去重，显示路程、技能、熟悉程度及排除原因。人工选择仍需在弹窗确认后提交。
- 订单管理：合并服务名称与订单号，把次要操作放入「更多」；保留详情、改派、代确认、取消等原有操作。修复字符串总数使分页无法显示的问题。
- 小程序：完成首页、服务列表与详情、预约、订单列表与详情、评价、服务工作台、个人中心、家属代约和档案登记共 11 个页面的样式统一。
- 图标：使用项目已有 Element Plus 图标体系，保留 SVG 源图，并生成微信可用的透明 PNG 与原生 TabBar 图标；许可文件位于 assets/icons 下。
- 长辈模式：以正文、标题、说明文字及控件尺寸变量分层放大，保留换行与底部安全区；不再对所有元素一刀切设置字号。
- 易用性：服务列表增加加载失败重试；首页服务分类使用 switchTab 并传递分类，修复跳转到原生 TabBar 页面的问题；演示入口收纳到次级区域。

## 本地查看

后台在 admin-web 目录运行 npm run dev，本地地址为 http://localhost:3000。小程序使用项目现有微信开发者工具配置，编译 miniprogram 目录；先检查「首页 → 服务分类 → 预约」，再切换大字版检查长文本与表单。
