# 真机调试网络说明

## 本次问题

手机真机调试中，登录与服务列表请求均报 `errno: 600002 / url not in domain list:localhost`。本地项目配置已关闭域名校验，但旧的真机调试会话仍在请求 localhost；手机的 localhost 指向手机自身。

电脑 WLAN 地址会随网络变化。开发环境在后端启动时探测当前局域网 IPv4，并写入未提交的 `miniprogram/config/local.js`（已加入 .gitignore）。真机会把缓存里的 localhost 和私网 IP 迁到这次探测到的地址。此项检查不能证明手机到电脑的网络已经连通。旧地址未同步时，真机继续请求会报 `ERR_CONNECTION_TIMED_OUT`。

## 已修改

- `miniprogram/app.js` 按 `wx.getAccountInfoSync().miniProgram.envVersion` 选地址：体验版/正式版（trial/release）固定使用 `PROD_BASE_URL`（HTTPS），开发版（develop）才读取 `config/local.js` 中的局域网地址；仓库里不再出现任何局域网 IP。
- 开发环境启动后端时运行 `miniprogram/scripts/sync-lan-ip.cjs`（Node 不可用时由 Java 回写），按当前网卡生成 `config/local.js`。探测会跳过 VPN、Clash fake-ip、WSL/Hyper-V 虚拟网卡，优先 WLAN/Wi-Fi。
- App 启动时识别平台：开发者工具默认 localhost，手机默认使用 `config/local.js` 中的局域网地址；该文件不存在时退回 localhost，可在个人中心手动填写。
- 手机保存过的 localhost、127.*、IPv6 回环地址以及 `10/8`、`192.168/16`、`172.16/12` 私网地址会迁到当前局域网地址；HTTPS 等正式地址继续保留。
- 手机的服务地址菜单只提供局域网和手动输入，避免再次选到电脑回环地址。
- 网络失败不再弹出“微信授权环境未配置”的演示登录引导，保留实际网络错误提示。

## 启动模块错误的补修

真机运行包曾出现 `utils/server-config.js is not defined`，使入口在调用 App 之前抛错，随后页面与 TabBar 获取不到 globalData。磁盘文件存在、require 路径正确，但开发者工具打包日志将这个新增文件列为忽略文件。

`config/local.js` 用 try/catch 加载：文件缺失或模块不可加载时 App 仍能注册并退回 localhost。回归测试覆盖：体验版/正式版只用 HTTPS 地址、提交的 app.js 不含私网 IP、缺少本地配置时的回退。

另观察到运行中的开发者工具将私有配置的 urlCheck 写回 true。已关闭当前工程后保存 false，再重新打开，避免旧运行配置覆盖文件。再次遇到同类情况时，应检查 project.private.config.json 的实际内容，并在关闭工程后保存配置再打开。

## 加载与验证

1. 手机和电脑连接可互访的同一局域网。
2. 结束旧的真机调试，电脑重新编译项目，再开启真机调试并用手机重新扫码。仅刷新旧会话可能继续使用旧代码或旧配置。
3. 本地开发时，确认微信开发者工具“详情 → 本地设置”中的“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”处于勾选状态；项目和私有项目配置中的 `setting.urlCheck` 均为 false。
4. 检查电脑弹出的“真机调试”独立窗口：右侧信息栏 → 设置 → 勾选“不校验合法域名、web-view（业务域名）”。本次实际观察到主工程 urlCheck 已是 false，但这个窗口的复选框未勾选，手机仍对局域网地址报 600002。不能仅凭模拟器请求成功判断真机设置已生效。
5. 换网后先重启后端（或执行 `node miniprogram/scripts/sync-lan-ip.cjs`），再重新编译小程序并扫码。控制台应出现 `lan-sync` / “真机调试地址已同步”。请求地址应是当前电脑 WLAN IP，而不是 localhost 或上一次的局域网地址。地址正确但仍报 `url not in domain list` 时，应先处理当前会话的域名校验。
6. 若地址正确但连接超时，用手机浏览器访问 `http://当前电脑IP:8080/api/service-items/list-available` 验证连通性。浏览器也无法访问时，应排查：手机是否与电脑同一 WiFi、Windows 防火墙是否拦截 8080（公用网络会拦入站）、校园网/访客网是否开启 AP 隔离。以管理员身份执行：`netsh advfirewall firewall add rule name="AgedCare Backend 8080" dir=in action=allow protocol=TCP localport=8080 profile=any`。

本地址用于当前本地联调；正式发布需配置部署后的 HTTPS 服务地址。`config/local.js` 不会被提交；上传体验版/正式版前建议执行 `node miniprogram/scripts/sync-lan-ip.cjs --clear`（或从干净检出上传），即便打包进去，运行时在 trial/release 也会忽略它。`PROD_BASE_URL` 目前是占位域名，需替换为实际部署的 HTTPS 地址并在小程序后台配置合法域名。
